# sparkdiff

Spark validation gates for diff inputs before they hit prod.

**Site:** https://theworker02.github.io/sparkdiff/

## Install / run

```bash
git clone https://github.com/theworker02/sparkdiff.git
cd sparkdiff
node src/cli.js
node --test
```
